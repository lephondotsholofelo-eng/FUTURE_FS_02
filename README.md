# FUTURE_FS_02

## Overview

FUTURE_FS_02 is a full-stack web application that introduces backend logic and database integration. The project focuses on handling structured data, implementing CRUD operations, and improving application scalability.

## Tech Stack

* Next.js
* Node.js (API Routes)
* MySQL
* Tailwind CSS

## Features

* Full CRUD functionality (Create, Read, Update, Delete)
* Integration with a MySQL database
* API routes for handling backend logic
* Structured data management
* Modular and scalable project architecture

## Project Structure

```
/app
/components
/lib
/api
```

## Installation and Setup

1. Clone the repository:

```
git clone https://github.com/lephondotsholofelo-eng/FUTURE_FS_02.git
```

2. Navigate into the project:

```
cd FUTURE_FS_02
```

3. Install dependencies:

```
npm install
```

4. Configure environment variables:
   Create a `.env.local` file:

```
DATABASE_URL=your_mysql_connection_string
```

5. Run the development server:

```
npm run dev
```

## Database

This project uses MySQL for data storage and management. The schema includes structured tables designed to support application functionality.

## Purpose

This project demonstrates backend development skills, database design, and integration within a modern web application.
